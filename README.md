# Queue-Based Ticket Reservation System

## Description
A queue-based ticket reservation system developed in C using a singly linked list.
The system follows the FIFO (First In, First Out) principle to handle ticket booking and cancellation efficiently.
This project demonstrates core data structures concepts, pointer manipulation, and dynamic memory allocation in C.

## Key Features
- Ticket booking using enqueue operation.
- Ticket cancellation using dequeue operation.
- Display of current waiting list.
- Menu-driven console application.

## Data Structures and Concepts
- Queue (FIFO)
- Singly Linked List
- Front and Rear Pointers
- Dynamic Memory Allocation
- Pointers in C

## Technologies
- Language: C
- Platform: Console Application

## Learning Outcomes
- Practical implementation of queue data structure.
- Efficient handling of enqueue and dequeue operations.
- Improved understanding of linked lists and pointers.
